Problem Statement & Core Thesis

Architecture Principle

Why Manual Chart Review Breaks Down

  • Patient histories span multiple specialists, years, lab panels, and prescription adjustments.
  • Clinicians miss recurring symptoms or earlier drug allergies buried in unstructured progress notes.
  • Unconstrained LLM chatbots invent diagnoses or misstate medication dosages when fed raw text.

Our Thesis: SQL Computes Facts, AI Writes Cited Prose

  • Relational SQL calculates recurrence counts, HbA1c trajectories, and date windows deterministically.
  • Every database row carries a typed primary-key tag ([V-1], [SYM-2], [DX-3], [RX-4]).
  • The validation gate drops any AI claim lacking a verified record tag and surfaces missing fields directly.

3NF Relational Database Design

PostgreSQL 16 + SQLite
Identity & Access

Users, Roles, Doctors

  • roles separates Admin and Doctor privileges.
  • users stores bcrypt hashes and active status.
  • doctors holds license numbers, department, and specialization.
  • patient_doctor models M:N care assignments.
Patient Core

Patients, Allergies, History

  • patients stores demographics and unique MRNs.
  • allergies enforces reaction severity CHECK rules.
  • medical_history tracks chronic, past, surgical, and family history.
  • Partial index covers active patient lookups.
Encounter Graph

Visits & 5 Child Tables

  • visits links patient, doctor, vitals, and treatment plan.
  • symptoms, diagnoses, clinical_notes, and test_results cascade on visit delete.
  • prescriptions joins visits to medications without transitive dependencies.

Hardened Constraints & Index Coverage

Every foreign key column carries an explicit B-tree index. Database CHECK constraints enforce sex, visit type, diagnosis status, heart rate (20 to 300 bpm), and SpO2 (50 to 100%).

Citation-Grounded AI Summarisation

4-Stage Pipeline
Stage 01

Eager SQL Load

Single joined-load query fetches visits, symptoms, diagnoses, prescriptions, notes, labs, and allergies.

Stage 02

Fact Aggregator

Python groups recurring symptoms, ICD-10 status transitions, repeat prescriptions, and longitudinal lab trends.

Stage 03

Citation Validator

validate_statements() verifies every emitted tag against citation_index and strips unverified references.

Stage 04

Review & Cache

Clinicians click badges to inspect rows, flag questionable claims, and auto-invalidate caches on record updates.

Diagnostic Conflict & Missing Data Detection

  • Flags status progressions such as Tension-Type Headache (Ruled-out) → Migraine with Aura (Confirmed) on MRN-2026-00001.
  • Explicitly surfaces missing blood groups or emergency contacts (demonstrated on MRN-2026-00006) instead of guessing.

Source Record Inspector & Claim Flagging

  • Every badge like [SYM-1] or [LAB-4] opens a side drawer displaying the raw primary-key row.
  • Clinicians mark suspect AI claims via the per-statement Flag Issue control directly in the summary panel.

Intelligent Historical Retrieval

Hybrid NL Query Engine

How Natural-Language Questions Execute

  • Temporal Parser: Extracts phrases like "last two years" into UTC date boundaries.
  • Table Intent Router: Maps terms such as diagnoses, prescribed, or labs to target relational tables.
  • Clinical Synonym Expander: Maps everyday queries ("sugar", "bp", "headaches") to clinical terms ("HbA1c", "hypertension", "migraine").
  • Relevance Ranking: Scores matching records by term hit weight and recency, returning source cards beside the explanation.

Zero-Hallucination Refusal Guard

When a clinician asks about an unrecorded condition (for example, "Find previous records mentioning Ebola"), the retriever returns zero matches and skips prose synthesis.

total_matches = 0
→ "No matching clinical records were found in the database for this query. The AI module does not extrapolate or invent clinical facts."

Security, RBAC & Clinical UX Craft

Governance & Accessibility
Session Security

Bcrypt + Session JWT

  • Passwords salted and hashed via bcrypt.
  • JWT credentials stored in sessionStorage rather than persistent local storage.
  • Logout clears all session tokens immediately.
Audit Trail

Filterable Action Logs

  • Logs logins, demographic edits, visits, and AI calls.
  • Records user identity, role, patient ID, and UTC timestamp.
  • Filterable live inside the Audit Trail view.
